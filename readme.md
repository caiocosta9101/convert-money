💱 Conversor de Moedas (Currency Converter)

Aplicação web para conversão de moedas em tempo real, utilizando dados atualizados da AwesomeAPI.

💻 Sobre o Projeto

Projeto desenvolvido para compor meu portfólio Front-end, com foco no consumo de APIs externas e na criação de interfaces dinâmicas com JavaScript.

A aplicação permite ao usuário informar um valor em moeda estrangeira e obter sua conversão para Real Brasileiro (BRL) com base na cotação atual, retornada em tempo real pela API.

✨ Funcionalidades

Conversão em Tempo Real: Consumo de API REST para obtenção de cotações atualizadas.

Interface Dinâmica: As opções de moedas são geradas via JavaScript, facilitando manutenção e escalabilidade.

Tratamento de Erros: Feedback visual ao usuário em caso de falha na API ou problemas de conexão.

Formatação de Valores: Exibição automática no padrão monetário brasileiro (pt-BR).
